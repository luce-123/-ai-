常见问题解答

我已经购买了通用 Token Plan（原 Token Plan），还能再购买 Hy Token Plan 吗 ？
可以。每个主账号（包含其名下的所有子账号）最多可同时持有 2 个​ Token Plan：1 个通用 Token Plan（不区分 Lite、Standard、Pro、Max 等具体套餐规格）、1 个 Hy Token Plan（不区分 Lite、Standard、Pro、Max 等具体套餐规格）。
如何抵扣我套餐包的用量？
通用 Token Plan 与 Hy Token Plan 共用同一套 API Key 和 URL，系统将根据您调用时指定的 Model ID，自动从支持该 Model ID 的对应套餐包中抵扣额度，详见 Token Plan 个人版积分用量抵扣规则。
Token Plan 可以生成多个 API Key 吗？
不可以，Token Plan 个人版套餐（含通用 Token Plan 套餐和 Hy Token Plan 套餐）仅支持生成一个 API Key 。
Token Plan 套餐是否支持团队协作使用?
目前 Token Plan 主要面向个人开发者。团队协作使用，请使用 Token Plan 企业版 服务。
是否可以使用模型列表以外的模型？
