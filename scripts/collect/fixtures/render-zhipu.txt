有什么不清楚的，随时问我
GLM-5.3-Flash 和 OX Alpha 是同一个模型吗？

OX Alpha 是 GLM-5.3-Flash 在内测阶段使用的内部代号。目前该模型已全面上线，支持正式调用。如需了解更多模型详情，请参阅完整的模型介绍文档。

套餐的用量额度限制是多少？

GLM Coding Plan 提供 3 种订阅套餐，满足不同开发场景的需求。为了管理资源并确保所有用户的公平使用，我们执行每 5 小时和每周的使用额度限制。 您可以在 用量说明 查看最新套餐的用量额度说明，以选择适合您的套餐。

套餐所支持的模型有哪些？

所有套餐用户均支持 GLM-5.3-Flash（OX Alpha）、GLM-5.3，查看模型调用 配置文档。

团队套餐相关的问题？

1. 默认情况下，管理员账号不占用团队席位。如需使用席位，管理员可给自己的账号分配一个席位，加入席位后即可享有相应额度。

2. 暂不支持支持高级版+标准版一起混着买

3. 同一个席位仅限单名成员使用，不支持多人共享。若多人同时使用，将触发风控机制。如需多人协作，建议按需购买多个席位。

4. 暂不支持标准版升级至高级版，敬请期待后续版本更新。

5. 每个席位账号下支持最多创建5个 API Key。

购买 GLM Coding Plan 后如何申请发票？支持哪些发票类型？

您可以进入智谱开放平台的发票申请页面，根据页面展示的可开票订单自助申请。发票开具后，会自动发送至您提交的邮箱，您可以通过邮件中的链接下载。

GLM Coding Plan 套餐额度与 API 余额是什么关系？

GLM Coding Plan 套餐额度与标准 API 是相互独立的，分别适用于不同的调用场景。GLM Coding Plan 套餐额度仅限在官方支持的编码工具和产品环境中使用；在自建应用、网站、机器人、SaaS 产品或其他场景中需要直接调用标准 API，不能使用套餐额度。
